# Changelog

Toutes les modifications notables de Kandidat sont documentées ici.

## [1.0.0] - 2026-03-22

### Ajouté

- Suivi de candidatures avec tous les champs : entreprise, poste, type, date, statut, lien offre, contact RH, notes, prochaines étapes
- 7 statuts de candidature : Brouillon, Envoyée, Relancée, Entretien, Offre reçue, Refus, Retirée
- 5 types de contrat : Stage, Alternance, CDI, CDD, Freelance
- Filtrage par statut, type et recherche textuelle
- Tri par date, entreprise ou statut
- Alertes visuelles pour les relances et entretiens à venir
- Barre de statistiques par statut
- Export des données en CSV et JSON
- Stockage persistant dans AppData (survit aux mises à jour)
- Installeur Windows (NSIS) avec raccourci Bureau et Menu Démarrer
- Détection de l'installation existante lors de la réinstallation
- Builds automatiques pour Windows, macOS et Linux via GitHub Actions
- Dark mode
